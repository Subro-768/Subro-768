### 🚀 Featured Project

#### [NexusFlow — Resumable Local Network File Transfer](https://github.com/Subro-768/NexusFlow)
> **Android (Kotlin / Jetpack Compose) + Linux Client**

- High-efficiency chunking protocol tested over live sockets with automated window-driven benchmarks.
- Built for GDG on Campus SRM 2026-27.
