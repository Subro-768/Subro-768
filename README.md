### 🚀 Featured Project

#### [NexusFlow — Resumable Local Network File Transfer](https://github.com/Subro-768/NexusFlow)
> **Android (Kotlin / Jetpack Compose) + Linux Client (Python)**

NexusFlow is a high-reliability local network transfer application built for **GDG on Campus SRM 2026-27**:
- **Fault-Tolerant Protocol**: Designed to survive sudden Wi-Fi disconnections, mobile app termination mid-transfer, duplicate chunk requests, and unexpected peer cancellation without data corruption.
- **Cross-Platform Pairing**: Android app paired with a native Linux desktop companion peer sharing the same protocol offsets and transfer controls.
- **Empirical Benchmarks**: Performance and reliability validated through automated socket benchmark suites.
