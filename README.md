## 🚀 Featured Projects

### [NexusFlow — Resumable Local Network File Transfer](https://github.com/Subro-768/NexusFlow)
**Android (Kotlin / Jetpack Compose) + Linux client (Python)**

A local-network transfer application built for **GDG on Campus SRM 2026–27**, with a focus on reliable transfers across real-world disconnects.

- **Fault-tolerant transfers:** handles Wi-Fi loss, app termination, duplicate chunk requests, and peer cancellation without corrupting transferred data.
- **Cross-platform pairing:** Android and Linux clients share protocol offsets and transfer controls.
- **Measured reliability:** automated socket benchmarks validate performance and recovery behavior.

### [NexusTrade — Market Research & Paper Trading](https://github.com/Subro-768/NexusTrade)
**React / TypeScript + Tauri desktop client · FastAPI + SQLite service**

A desktop workspace for Indian-market research and simulated paper trading.

- **Clear data provenance:** distinguishes mock, stale, delayed, and unavailable market data.
- **Risk-checked paper workflow:** server-side preview and deterministic risk checks precede explicit user confirmation.
- **Local-first design:** the desktop client communicates with a local API; the paper ledger is separate from legacy wallet records.

> NexusTrade is for research and simulated trading. It does not send orders to a broker or execute real-money trades.
